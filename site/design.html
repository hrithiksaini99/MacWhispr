Capture contract

Record for inference, meter for feedback.

AVAudioRecorder writes the model ready WAV while a 50 ms timer reads peak decibels. The highest sample also rejects recordings with no usable speech before inference begins.

Process contract

Keep engine output off memory pipes.

The child process writes stdout and stderr to private temporary files. This avoids a deadlock when a verbose backend fills a pipe, bounds diagnostics, and gives cancellation one process to terminate.

Focus contract

Remember where the thought started.

The frontmost application is captured before recording. After transcription it is reactivated, allowed 120 ms to regain focus, then receives a synthetic Command V after the text reaches the pasteboard.

Build it in dependency order

Seven layers.
A test after each one.

This order keeps platform permissions, process control, and interface polish from becoming one large debugging problem.

  1. 01

    Create the accessory app shell.

    Build a SwiftPM executable, start NSApplication manually, set the activation policy to accessory, add LSUIElement, and create an NSStatusItem.

    Checkpoint: the app launches with a menu bar icon and no Dock icon.
  2. 02

    Register one global shortcut.

    Install a Carbon event handler for pressed and released events. Translate NSEvent key codes into Carbon modifiers and register the combination with a stable signature and ID.

    Checkpoint: Toggle and Push to Talk both produce deterministic start and stop callbacks.
  3. 03

    Capture model ready audio.

    Request microphone access, discover input devices, and configure AVAudioRecorder for 16 kHz mono signed PCM. Sample metering every 50 ms.

    Checkpoint: the WAV opens in another audio tool and the meter responds to real speech.
  4. 04

    Wrap the speech engine.

    Resolve the bundled helper first, launch it with Process, isolate output on disk, calculate a recording based timeout, and support termination plus a delayed SIGKILL.

    Checkpoint: success, nonzero exit, timeout, and cancellation all clean up their temporary files.
  5. 05

    Return text without stealing focus.

    Capture the frontmost app before recording. Put the transcript on NSPasteboard, restore the app, and emit Command V through CGEvent after checking Accessibility trust.

    Checkpoint: dictation begun in a text field returns to that exact app and inserts once.
  6. 06

    Add honest visual feedback.

    Host SwiftUI in a borderless, nonactivating NSPanel. Drive the listening canvas from real meter values and use repeating activity traces for transcription.

    Checkpoint: keyboard focus never leaves the destination and Reduce Motion removes continuous animation.
  7. 07

    Package the runtime as one product.

    Place the executable, icon, licenses, and statically linked speech helper in the app bundle. Sign the helper before the app, submit the ZIP for notarization, staple, and assess with Gatekeeper.

    Checkpoint: the archived app launches on a clean Apple Silicon Mac without Homebrew.

Engineering decisions

The edges that make
the app reliable.

These details are easy to miss in a prototype and expensive to discover after shipping.

Register before saving

A custom shortcut is persisted only after Carbon accepts it. Closing a failed recorder restores the previous working combination.

Validate the model twice

Downloads must pass a size threshold, expected content length check, and the four byte GGML magic value before installation.

Own the child process

The app stores the transcription task, cancels it on quit, terminates the engine, then escalates to SIGKILL after two seconds if needed.

Preserve the clipboard result

If Accessibility is denied, the transcript still stays on the clipboard and the user receives a clear recovery step.

Do not fake progress

Model downloads report real byte progress. Transcription shows activity because whisper.cpp does not expose a trustworthy completion percentage here.

Delete on every exit path

Temporary audio, process output, and diagnostics are removed after success, error, timeout, cancellation, or application termination.
