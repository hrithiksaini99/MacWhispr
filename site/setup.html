Get MacWhispr

A small start.
A new way to write.

The Apple Silicon developer preview includes the local transcription engine. Choose a model and set up macOS permissions to begin.

Preview availability

The current candidate is prepared for local evaluation. Apple Developer ID signing and notarization are still pending, so a public production download is not available yet.

Installation instructions below apply to the preview package once it is supplied. A public download will be linked here after the signing and release checks are complete.

1. Put the app in Applications

Unzip the preview package and move MacWhispr.app into Applications. Open it from there. The app lives in the menu bar and does not show a Dock icon or a main window.

The packaged preview targets Apple Silicon and macOS 13 or later. Intel builds have not yet been verified.

2. Download a model

Open the MacWhispr menu and choose a model. Base (English) is the default and downloads about 148 MB. The menu shows download progress. Larger models need more storage and can take longer to transcribe.

Model downloads need internet access and use Hugging Face. Once a model is installed, dictation runs locally without a connection.

3. Allow the permissions

  • Microphone: allow the prompt so MacWhispr can record your speech.
  • Accessibility: enable MacWhispr in System Settings → Privacy & Security → Accessibility to paste into the app you were using.
  • Notifications: optional, for error messages that need attention.

If Accessibility access is unavailable, the transcript remains on your clipboard for manual paste with Command V.

4. Say something worth keeping

Focus a text field. Press your shortcut, speak, then press it again. The capsule changes from listening to transcribing, and confirms after MacWhispr has inserted the text.

Control Space is the default. Choose Shortcut in the menu to record your own combination. For Push to Talk, hold that shortcut while speaking and release it to finish.

Make it yours

Choose Shortcut to personalize the global recording key. MacWhispr checks that the combination is available before saving it.

Use Input Device in the menu to select a microphone. A specific device selection changes the macOS default input, so other apps using that input can be affected.

Use Open Model Folder to inspect local model files. The app stores them in Library → Application Support → MacWhispr → models under your user account.

If something needs attention

  • If a shortcut is already in use, record a different combination in the shortcut panel.
  • If text is copied but not inserted, check Accessibility permission or paste manually. Secure fields may reject automatic paste.
  • If no speech is detected, confirm your input device, unmute it, and try a short recording.
  • If a model download fails, check your connection and available disk space, then choose the model again.
