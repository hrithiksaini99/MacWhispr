The useful details

Privacy, in plain words.

MacWhispr processes speech on your Mac. This page describes what the app stores, where it connects, and what remains after dictation.

Last updated October 4, 2026

Your audio and transcript

MacWhispr records a temporary WAV file and transcribes it locally using whisper.cpp and your selected model. It does not upload recordings to a transcription service.

Temporary recordings are removed when processing finishes or fails. An abrupt app exit or system failure can leave a recording in the macOS temporary directory.

The latest transcript is placed on the macOS clipboard. MacWhispr does not keep a transcript history database. Clipboard managers and macOS clipboard features may retain or share clipboard text according to their own settings.

Models and network connections

Downloading a model contacts the whisper.cpp model repository on Hugging Face and its download infrastructure. Those services may receive ordinary connection information, such as your IP address. Their own privacy terms apply.

After the engine and model are installed, recording and transcription can run without a network connection. MacWhispr has no account system, cloud transcription API, or analytics integration.

Settings and local storage

Activation mode, selected model, and preferred microphone are saved in macOS UserDefaults. Model files are stored under your user account in Library → Application Support → MacWhispr → models.

You can inspect the model directory using Open Model Folder in the app menu. Remove downloaded models there when you no longer need them.

Permissions

Microphone permission lets MacWhispr record speech. Accessibility permission lets it return to the app you were using and send the paste shortcut. Notifications are optional and are used for error messages.

You can revoke these permissions in System Settings → Privacy & Security. Choosing a specific microphone changes the system default input device, which may also affect other apps.

Local diagnostics

The app writes operational events and errors to local macOS logging. Successful transcripts are not printed to app logs. Engine errors can contain diagnostic details. Review diagnostic captures before sharing them.

This website

This static website does not use cookies, analytics, advertising scripts, forms, or microphone access. The interactive demo is illustrative and does not record or transcribe audio. Fonts and visual assets are served with the page.

A hosting provider may receive ordinary web request information when you load the website. External links take you to services with their own privacy practices.

Changes and questions

This page describes the current developer preview. It will be updated if the app begins collecting or processing data differently. The app is built by Hrithik Saini.
